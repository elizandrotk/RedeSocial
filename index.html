How to Host on GitHub Pages

Follow this simple step-by-step guide to publish **WorldConnect** online for free in under 3 minutes!

1

Create a GitHub Repository

Go to GitHub, click **New Repository**, and name it worldconnect or your-username.github.io.

2

Save as index.html

Save this complete code inside a file named exactly index.html and upload it to the root of your GitHub repository.

3

Enable GitHub Pages

In your repository, go to **Settings** → **Pages**. Under **Source**, select the main branch and folder / (root). Click **Save**.

4

You're Live!

In less than a minute, your web application will be live at: https://your-username.github.io/worldconnect/
