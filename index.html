Como Hospedar no GitHub Pages

Siga este passo a passo simples para publicar o **WorldConnect** no GitHub gratuitamente em menos de 3 minutos!

1

Crie um Repositório no GitHub

Acesse o GitHub, clique em **New Repository** e nomeie como worldconnect ou seu-usuario.github.io.

2

Envie este Arquivo HTML

Salve todo este código em um arquivo exatamente chamado index.html. Faça o upload dele na raiz do repositório no GitHub.

3

Ative o GitHub Pages

No seu repositório, vá para **Settings** → **Pages**. Em **Source**, selecione a branch main e a pasta / (root). Clique em **Save**.

4

Pronto! Seu site está online

Em cerca de 1 minuto, seu link estará disponível em: https://seu-usuario.github.io/worldconnect/
