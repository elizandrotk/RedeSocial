Como Hospedar no GitHub Pages Gratuitamente

Siga os passos abaixo para colocar sua rede social no ar para todo mundo acessar.

  1. Crie uma conta e um Repositório no GitHub:

    Acesse github.com, clique no botão New Repository. Defina o nome (ex: worldconnect-social) e marque como Public.

  2. Envie este arquivo de código:

    Dentro do repositório criado, clique em Add file > Create new file. Renomeie o arquivo para index.html, cole todo o código deste arquivo e clique no botão verde Commit changes.

  3. Ative o GitHub Pages:

    Vá na aba Settings do seu repositório > no menu esquerdo clique em Pages > em Branch selecione main (ou master) e /root > clique em Save.

Pronto!

Em cerca de 2 a 3 minutos, seu site estará rodando ao vivo no endereço https://seu-usuario.github.io/worldconnect-social/.
